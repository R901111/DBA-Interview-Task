## 📂 目錄與各題解答重點

### [Q1：訂單資料表設計與分區策略](./Q1/)
* **亮點**：規劃 `(OrderId, CreatedAt)` 為複合主鍵以達成 Partition Alignment。
* **決策**：計算資料量後，採用**「按月分區 (Monthly Partitioning)」**策略，並針對狀態欄位優化資料型別以節省儲存空間。

### [Q2：災難還原策略 (PITR)](./Q2/)
* **亮點**：提出避免覆蓋正式環境的防禦性救援計畫。
* **決策**：不直接進行還原覆蓋，而是採用 **Side-by-side Restore (還原至旁系資料庫)** 搭配 `STOPAT` 參數精準倒帶，再將資料安全搬回。

### [Q3：預存程序效能調校](./Q3/)
* **亮點**：解決 SARGable 失效與 TempDB 濫用問題。
* **驗證**：透過 `SET STATISTICS IO ON` 觀察，成功將 `Clustered Index Scan` 優化為 `Index Seek`，並大幅降低 I/O 消耗。

### [Q4：高併發下的資料一致性](./Q4/)
* **亮點**：解決 TOCTOU (Race Condition) 造成的重複寫入漏洞。
* **決策**：確立「資料庫層」為最終防禦責任歸屬。利用 `CTE + ROW_NUMBER()` 清理重複資料，並在底層加上 `UNIQUE CONSTRAINT` 阻擋並發。
